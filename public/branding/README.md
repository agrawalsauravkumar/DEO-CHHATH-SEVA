# DEO CHHATH SEVA — Official Branding Assets
# NEXTGEN DEVBHOOMI FOUNDATION
# "रास्ता भी • सहायता भी • सेवा भी"

`deo-chhath-seva-logo.png` is the canonical full application logo supplied by the
foundation. The splash screen and brand/social surfaces use this complete logo.
`deo-chhath-seva-icon-192.png` and `deo-chhath-seva-icon-512.png` are derived from
the logo's sunrise illustration for small launcher surfaces where the full wordmark
would not remain legible. Keep the canonical logo as the source of truth.

This directory also contains supplementary icon assets:

1. `deo-chhath-seva-icon.svg`
   - High-contrast square squircle app icon for desktop, tablets, and mobile home-screens.

2. `deo-chhath-seva-favicon.svg`
   - High-clarity circular vector favicon with rising sun, holy ghat waters, and golden diya.

4. High-density PNG exports:
   - `deo-chhath-seva-logo.png` (canonical application logo)
   - `deo-chhath-seva-icon-192.png`, `deo-chhath-seva-icon-512.png` (launcher icons)
   - `deo-chhath-seva-maskable-192.png`, `deo-chhath-seva-maskable-512.png`
     (safe-zone padded launcher icons)
